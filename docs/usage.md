# 使用说明

## 基本交互

- **收起态**：屏幕顶部居中的黑色胶囊，显示时间与天气概要。
- **展开**：鼠标悬停到胶囊上，面板自动展开。
- **收起**：鼠标移出面板后自动收起。
- **退出**：系统托盘图标右键菜单，或展开面板右上角 ⚙ 设置菜单中的「退出 WinIsland」。

## 面板内容

| 区域 | 内容 |
| --- | --- |
| 顶部 | 完整日期、星期与当前时间，右侧为设置菜单 |
| 天气卡片 | 当前温度、天气状况、城市、最高/最低温（当前为示例数据） |
| 日历 | 当月日历，可用左右箭头切换月份 |

## 数据说明

天气数据当前为示例数据（卡片上有「示例数据」徽标说明），后续版本接入真实天气源。
