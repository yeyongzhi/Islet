# 使用说明

## 基本交互

- **收起态**：屏幕边缘的黑色胶囊（顶部为完整胶囊，侧边纵向显示所选信息），显示时间/番茄钟与天气概要。
- **展开**：鼠标悬停到胶囊上，面板自动展开。
- **收起**：鼠标移出面板后自动收起。
- **移动位置**：按住胶囊（或面板顶部时间栏）拖动，松手后自动吸附到最近的屏幕边缘（上/左/右/下）。
- **切换面板**：使用两侧箭头、底部导航或鼠标滚轮；灵动岛获得焦点时也可按 Ctrl + 左右方向键。可在通用设置中隐藏两侧按钮。
- **设置**：面板右上角 ⚙ →「打开设置」；或托盘右键。
- **收起样式与内容**：在设置中选择刘海、胶囊或指示条，按需启用并调整收起内容；项目过多时可能被截断。
- **更新**：正式安装版会检查更新；新版本提供校验文件时，下载完成后自动启动覆盖安装。
- **退出**：面板 ⚙ 菜单中的「退出 Islet 灵岛」，或托盘菜单。

## 面板一览

通过设置窗口的「面板」选择需要的内容，并调整显示顺序。可用面板及用途见[面板清单](./features)。

相册默认留空，可在面板设置中选择本机图片；图片按三列滚动展示，点击打开，右键可移除或打开所在文件夹。快速启动支持本地路径与网址。

## 数据说明

- 天气数据来自 Open-Meteo（免费、无需 Key）。
- 剪贴板历史仅收集文本，仅保存在本次运行期间。
- 设置持久化于安装目录 `setting/preferences.json`；健康计数在 `data/counters.json`。
