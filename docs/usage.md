# 使用说明

## 基本交互

- **收起态**：屏幕边缘的黑色胶囊（顶部为完整胶囊，侧边为小方块），显示时间/番茄钟与天气概要。
- **展开**：鼠标悬停到胶囊上，面板自动展开。
- **收起**：鼠标移出面板后自动收起。
- **移动位置**：按住胶囊（或面板顶部时间栏）拖动，松手后自动吸附到最近的屏幕边缘（上/左/右/下）。
- **切换面板**：面板左右两侧的箭头翻页，或点击底部指示点直达。
- **设置**：面板右上角 ⚙ →「打开设置」；或托盘右键。
- **退出**：面板 ⚙ 菜单中的「退出 Islet 灵岛」，或托盘菜单。

## 面板一览

| 面板 | 内容 |
| --- | --- |
| 日历（默认） | 当月日历 + 天气概要 |
| 天气 | 当前温度/状况 + 未来 6 天预报，可输入城市切换 |
| 音乐 | 读取本机网易云/QQ 音乐等播放器的曲名、进度，支持播放/暂停/切歌 |
| 番茄专注 | 专注/休息计时，运行时胶囊显示倒计时 |
| 剪贴板 | 文本历史（上限 50 条），点击条目复制回剪贴板 |
| 健康 | 喝水杯数（目标进度）+ 小手/大手当日计数，跨天自动清零 |

## 数据说明

- 天气数据来自 Open-Meteo（免费、无需 Key）。
- 剪贴板历史仅收集文本，仅保存在本次运行期间。
- 设置持久化于安装目录 `setting/preferences.json`；健康计数在 `data/counters.json`。
