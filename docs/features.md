# 面板清单

灵岛通过面板展示信息和常用工具。可在设置的「面板」中启用、关闭、排序和调整支持配置的面板；新启用的面板会出现在列表末尾。

## 信息面板

- **日历与日期时间**：查看当月日历、天气概要、当前时间与农历。
- **天气**：查看当前天气与未来预报，可在设置中选择城市。
- **时间进度、倒数日与日程**：追踪时间、重要日期和待办日程。
- **系统监控与磁盘**：查看系统资源和磁盘空间。
- **电池与电源**：查看电量、充电、电源计划及节电状态；没有电池时明确提示。
- **网络连接**：查看当前网络、互联网连接、可用的 Wi-Fi 信号及所有网卡的实时上传和下载速度。
- **汇率**：查看货币汇率信息。

## 工具面板

- **音乐控制**：查看和控制支持系统媒体控制的播放器。
- **番茄专注**：安排专注和休息时段。
- **倒计时器**：设置 1–1440 分钟，开始、暂停、重置，到时按通知设置提醒；切换面板后继续计时，退出应用后不保留。
- **音量控制**：调节默认输出设备音量、静音，并可打开 Windows 声音设置切换设备。
- **剪贴板**：搜索、固定和复制本次运行中的历史记录。
- **文件中转站**：暂存文件路径，方便拖放。
- **快速启动**：打开常用系统功能，也可添加和编辑本地路径或链接。
- **相册**：选择本机图片，以三列滚动浏览，可打开图片或所在文件夹。
- **下班倒计时**：查看距离下班、发薪和入职的时间。

## 健康面板

- **喝水与如厕**：记录当日次数。
- **久坐与护眼**：按设定间隔提醒休息。

面板的可用设置和数据来源请以应用内说明为准。
