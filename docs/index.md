# WinIsland

Windows 桌面灵动岛 —— 在屏幕顶部提供一枚常驻悬浮胶囊，展开即见日历、日期、时间与天气。

## 它是什么

WinIsland 常驻于屏幕顶部居中位置，默认收起为一枚黑色胶囊，显示当前时间与天气概要；鼠标悬停后自动展开为信息面板：

- 完整日期与时间（如「11月21日 周六 08:58」）
- 当月日历
- 天气卡片（当前版本为示例数据）

鼠标移出面板后自动收起，不遮挡正常工作。

## 适用场景

- 希望随时瞥一眼时间与日期，又不想打开日历应用的用户
- 需要在桌面快速查看天气概要的用户
- 喜欢灵动岛交互形态的 Windows 用户
