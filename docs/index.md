# WinIsland

Windows 桌面灵动岛 —— 在屏幕边缘提供一枚常驻悬浮胶囊，展开即见日历、天气、音乐、专注时钟与健康小工具。

## 它是什么

WinIsland 常驻于屏幕边缘，默认收起为黑色胶囊，显示当前时间（或番茄钟倒计时）与天气概要；鼠标悬停后自动展开为多面板信息站：

- 日历与日期时间
- 真实天气（今日 + 未来 6 天预报）
- 本机音乐播放状态与控制
- 番茄专注计时
- 剪贴板历史
- 喝水与上厕所计数

支持拖动换位与四边停靠；鼠标移出面板后自动收起，不遮挡正常工作。

## 适用场景

- 希望随时瞥一眼时间、日程与天气的用户
- 使用番茄工作法保持专注的用户
- 需要剪贴板历史或轻量健康打卡的用户
- 喜欢灵动岛交互形态的 Windows 用户
